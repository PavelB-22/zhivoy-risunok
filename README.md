# Живой рисунок

Ребёнок рисует зверька, фотографирует, и рисунок оживает на экране: рыбки плавают в море, львы и слоны гуляют по саванне, котики и собачки ходят по домику.

- У каждого свой аккаунт (логин и пароль) и свои рисунки.
- Три мира: **Море**, **Саванна**, **Домик**.
- На экране максимум 10 существ. Когда приходит новое, самое старое уходит, но остаётся в разделе «Для взрослых».
- Новый рисунок появляется на экране сам через несколько секунд. Можно включить море на телевизоре, а фотографировать с телефона под тем же аккаунтом.
- Если тыкнуть в зверька, он подпрыгивает или делает кувырок. Если тыкнуть в пустое место, летят пузырьки, цветочки или звёздочки.
- Настройки (шестерёнка) закрыты замком для родителей: нужно решить пример на сложение.
- В настройках есть вкладка **Раскраски**: 15 зверей (по 5 на мир), каждый можно скачать PDF-файлом формата А4 и распечатать.
- Ставится ярлыком на рабочий стол как обычное приложение (PWA).

## Из чего состоит

```
zhivoy-risunok/
├── wrangler.toml        ← настройки для Cloudflare (сюда вставить ID базы)
├── schema.sql           ← таблицы базы (один раз вставить в консоль D1)
├── package.json
├── src/worker.js        ← сервер: аккаунты, сохранение рисунков
└── public/              ← сам сайт
    ├── index.html, style.css
    ├── manifest.webmanifest, sw.js, icons/   ← ярлык на рабочий стол
    └── js/
        ├── app.js       ← экраны и кнопки
        ├── scene.js     ← море, саванна, домик и анимация
        ├── cutout.js    ← вырезание рисунка из фото
        ├── sound.js     ← звуки
        ├── art.js       ← иконки и картинки меню
        ├── templates.js ← 15 раскрасок и сборка PDF А4
        └── templates-real.js ← реалистичные зебра, жираф, попугай, акула, обезьянка
```

Код хранится на GitHub, а сайт и база работают на Cloudflare. GitHub ничем не нагружается.

## Запуск по шагам (≈15 минут)

### Шаг 1. Залей проект на GitHub

1. На github.com нажми **New repository** и назови его, например, `zhivoy-risunok`. Private или Public — неважно.
2. На странице пустого репозитория нажми **uploading an existing file**.
3. Перетащи туда **содержимое** папки `zhivoy-risunok`: файлы `wrangler.toml`, `schema.sql`, `package.json`, `README.md` и папки `src` и `public`. Нажми **Commit changes**.

### Шаг 2. Создай базу данных на Cloudflare

1. Зайди на dash.cloudflare.com и открой слева **Storage & Databases → D1 SQL Database**.
2. Нажми **Create database** и введи имя `zhivoy-risunok-db`.
3. На странице базы скопируй **Database ID**. Это длинный код вида `a1b2c3d4-....`
4. Открой вкладку **Console**, вставь туда весь текст из файла `schema.sql` и нажми **Execute**. Так создадутся таблицы.

### Шаг 3. Впиши ID базы в проект

1. На GitHub открой файл `wrangler.toml` и нажми на карандаш (Edit).
2. Вместо `ВСТАВЬ_СЮДА_ID_БАЗЫ` вставь скопированный ID, кавычки оставь.
3. Нажми **Commit changes**.

### Шаг 4. Подключи GitHub к Cloudflare

1. В Cloudflare открой **Workers & Pages → Create → Import a repository**.
2. Разреши Cloudflare доступ к GitHub и выбери репозиторий `zhivoy-risunok`.
3. **Project name** должно быть `zhivoy-risunok`, ровно как `name` в `wrangler.toml`.
4. Остальное оставь по умолчанию: Deploy command — `npx wrangler deploy`. Нажми **Deploy**.
5. Через минуту появится адрес вида `zhivoy-risunok.твой-ник.workers.dev`. Это и есть приложение.

### Шаг 5. Пользуйся

1. Открой адрес, нажми **Новый аккаунт** и придумай логин и пароль.
2. Ярлык на рабочий стол:
   - **Компьютер (Chrome / Edge):** значок «установить» в адресной строке или меню ⋮ → «Установить приложение».
   - **Android:** меню ⋮ → «Добавить на главный экран».
   - **iPhone / iPad (Safari):** кнопка «Поделиться» → «На экран «Домой»».
3. Распечатай раскраски: шестерёнка → реши пример → вкладка **Раскраски** → «Скачать». Получится PDF А4: печатай дома или неси в фотостудию.

### Как обновлять

Меняешь любой файл на GitHub, и Cloudflare через минуту сам выкладывает новую версию. Ничего нажимать не нужно.

## Полезно знать

**Как фотографировать, чтобы вырезалось хорошо:**
- лист целиком в кадре, телефон прямо над ним;
- дневной свет, без вспышки;
- контур лучше обвести тёмным фломастером, тогда незакрашенные места внутри тоже останутся частью зверька.

Если вырезалось плохо, в окне предпросмотра есть «Плохо вырезалось?» с ползунком. А кнопка со стрелками разворачивает рисунок, если зверёк смотрит не в ту сторону.

**Бесплатный тариф Cloudflare.** Для начала его с запасом хватает: у Workers около 100 000 запросов в день, у D1 несколько ГБ. Точные лимиты смотри на странице тарифов Cloudflare. Один открытый экран проверяет новые рисунки раз в 5 секунд, это примерно 17 000 запросов в сутки, если держать его открытым круглосуточно. Если экранов будет много, увеличь `POLL_MS` в `public/js/app.js`, например до 10000.

**Где лежат картинки.** Прямо в базе D1, одна картинка примерно 50–200 КБ. Это самый простой вариант. Если пользователей станет много, картинки лучше перенести в хранилище R2.

**Что настроить под себя:**
- лимит существ на экране: `SCREEN_LIMIT` в `src/worker.js`;
- размер и скорость зверей: функция `fit()` в `public/js/scene.js`;
- тексты и подсказки миров: объект `LOCS` в `public/js/app.js`;
- новые раскраски: добавь зверя в список `list` в `public/js/templates.js` (картинка рисуется кодом SVG);
- замок для родителей: функция `parentGate` в `public/js/app.js` (после верного ответа 10 минут не спрашивает).

## Идеи на потом

- QR-код на экране: ребёнок сканирует его телефоном и сразу загружает рисунок в этот аквариум.
- Ночной режим моря с фонариками и светящимися медузами.
- Новые миры: небо с птицами и бабочками, ферма, космос.
- Комнаты по ссылке без входа, чтобы раздать доступ на праздник или в группу садика.
